【三層寫法】（v10 核心，違反即返工）
1. 每節固定三層：先一句白話結論（headline 類欄位），再 2–3 句展開（body / flow / leak / one_line / text），命理依據只進「據」類欄位（dominant / secondary / latent / driver / evidence）。結論句要讓完全不懂命理的人一眼看懂。
2. 十神名第一次出現在展開層時，緊跟一句白話釋義，之後可直接用名字。釋義以本表為基準，可按本盤語境微調，不得與表意矛盾：
   | 十神 | 白話 |
   |---|---|
   | 比肩 | 自己的主見、和你同路的夥伴 |
   | 劫財 | 同輩之間的競爭、和人搶資源 |
   | 食神 | 自然流露的產出、手藝和享受 |
   | 傷官 | 表達欲、挑戰規矩的鋒芒 |
   | 偏財 | 抓機會、調動資源的嗅覺 |
   | 正財 | 穩定收入、慢慢存下來的積累 |
   | 七殺 | 外部壓力和硬要求 |
   | 正官 | 規則、職位和名分 |
   | 偏印 | 偏門的學識、一個人鑽研 |
   | 正印 | 體系、資歷和靠山 |
3. 數字只進據：結論層與展開層不得出現權重、五行計數等數字；唯一例外是「約 X 歲」這種年齡。
4. 大運寫法（v10 放寬）：展開層提到大運，統一寫成「約 X 歲起的那十年（某某運）」——X 必須是輸入大運裡那一步的起運歲數，括號裡必須是同一步的干支，兩者要對得上。干支**只允許**出現在這個緊跟年齡短語的括注裡；括注只寫干支和「運」，不加任何解釋。展開層的其他位置照舊不得寫出干支字，也不得寫「干支＋五行」註記（如「壬水」「庚金」式）——那些一律只出現在 evidence / driver / from / to 裡。依據必須來自輸入大運裡實際存在的大運，不得編造、不得照抄示例（示例只用 X 和「某某」佔位，不寫真實干支與歲數）：
  ✗「約 X 歲起的那十年走某某運」（干支寫在括注外）
  ✗「到了某某運，你會……」（沒有年齡短語）
  ✓「約 X 歲起的那十年（某某運），……」
  同節 evidence 裡照舊落錨「X 歲段：（該步實際干支）運」——括注是給讀者看的，evidence 是依據，兩處都要有。**結論層（headline / structure_type.name）仍然禁止任何干支，包括括注**。
5. 生活場景：全章至少一個具體場景，帶「什麼時候、對誰、做什麼」。
6. 不得複用示例：本提示詞裡出現的任何示例句（含共享部分的 ✓/✗ 示例、下方寫法示範）只演示寫法，內容一律不得照搬或改寫使用。
7. 結論層與展開層禁用工程腔與術語腔：通道、鏈條、輸出鏈、環節、轉換層、「X 端」（輸出端/吸收端/正印端）、「這一段/那一段」（指循環中的某段）、承載、權柄、洩漏、流失、鞏固、咽喉、缺位、對峙、通關。想表達這些意思時，改用可觀察的行為來寫。
8. 權重 >0 的十神或十神類別，任何欄位都不得寫成「缺位 / 缺失 / 沒有 / 不存在」——只有權重為 0 才能說「缺」。
