# IAP 商品文案(草稿 v0.1,2026-08-15 补)

> App Store Connect 内购字段:显示名称 ≤30 字符,描述 ≤45 字符(中文区)。
> 商品形态:消耗型 IAP per 命盘(MONETIZATION.md 拍板),无订阅。
> 合规口径:写清"按盘/按对计费"的消耗性质,苹果审核对消耗型必须明示购买单位。

## 商品 1:深度解析完整解读($17.99 / 消耗型)

**显示名称**(14 字符):
```
深度解析完整解读（单个命盘）
```

**描述**(约 40 字符):
```
解锁该命盘全部6章：十神结构、财运、爱情、健康、六亲、晚年。按盘计费，永久有效。
```

**备注口径**:免费部分(排盘+今日运势+每章试读)永久免费;每个新增/修改的命盘单独解锁。

## 商品 2:合盘完整解读($11.99 / 消耗型)

**显示名称**(12 字符):
```
合盘完整解读（单对关系）
```

**描述**(约 42 字符):
```
解锁这对关系的全部4章：爱情深度、合作事业、财运合拍、流年同步。按对计费，永久有效。
```

## 审核备注建议(提交 IAP 时填)

```
本商品为消耗型解锁,单位为"单个命盘(或单对关系)"的解读内容。App 内免费功能:
排盘、今日运势、每章试读。测试路径:输入任意出生信息 → 排盘 → 深度解析 Tab →
点击"生成免费解读" → 付费章节锁 → 触发购买。沙盒环境可完整走通购买与解锁流程。
```
