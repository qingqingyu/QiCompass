# 审核合规要点(草稿 v0.1)

> 命理类 App 在中国区 + 美区都有审核敏感点。这份清单把风险和应对集中管理。
> 原则:**合规话术与产品定位天然一致**——我们本来就"不讲吉凶、不做预测",只需要如实表达。

## 1. 内容红线(商店文案 + App 内文案统一口径)

### 禁用词(商店文案/截图/预览视频全适用)

| 禁 | 用 |
|---|---|
| 算命 / 占卜 / 看相 | 八字 / 命理 / 排盘 / 传统文化 |
| 预测 / 预言 / 推算未来 | 结构解读 / 倾向参考 / 自我认知 |
| 灵验 / 准到吓人 / 大师 | 确定性引擎 / 有依据 / 可追溯 |
| 改运 / 转运 / 化解 / 开运 | 调候建议 / 节奏参考(仅健康作息语境) |
| 婚姻注定 / 缘分天定 | 相处模式 / 关系结构 |

### 背书

- 后端已有 `forbidden_words` 禁词系统(注定/必然/破财/血光/克夫/大凶/劫难等拦截),App 内 AI 输出已强制过滤——审核时这是加分项,可在审核备注里说明。
- 产品页脚已有免责声明文案(医疗/心理/法律/投资),复用到商店描述末尾。

## 2. 中国区特有风险

| 风险 | 应对 |
|---|---|
| 「宣扬封建迷信」驳回 | 全程用「传统文化 + 命理文化 + 自我认知」框架;描述里强调"参考工具,不是判决书";不放八卦图/符咒/香炉类视觉 |
| ICP 备案要求(2023 起中国区强制) | 上架中国区需要 ICP 备案号填入 App 信息。**没有备案则只能先上美区/其他区**——这是排期上最大的前置依赖,需要尽早启动 |
| 个人开发者账号限制 | 确认账号类型;若企业账号,提前准备 DUNS |

## 4. 隐私政策要点(需一个可访问 URL)

内容清单:
1. 收集什么:出生日期时间/性别/出生地(经度时区)
2. 怎么用:排盘计算 + AI 解读生成;后端只存内容哈希做缓存,不存身份信息
3. 不做什么:不卖数据、不做广告追踪、无第三方 SDK 埋点(如实核对 Xcode 后填)
4. 用户权利:本地数据可删除(卸载即清除)
5. 联系方式

> App Store Connect「App 隐私」标签需与隐私政策一致,别写漏。

## 5. 年龄分级问卷建议作答

- 暴力/色情/赌博/药品:全部「无」
- 「不受限制的网络访问」:是(有后端 API)
- 「模拟赌博」:否
- 预期分级:**4+**;若因命理主题被要求抬到 12+,可接受
