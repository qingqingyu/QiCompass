# 审核合规要点(草稿 v0.2,T20 纠错)

> 命理类 App 在中国区 + 美区都有审核敏感点。这份清单把风险和应对集中管理。
> 原则:**合规话术与产品定位天然一致**——我们本来就"不讲吉凶、不做预测",只需要如实表达。
> v0.2(2026-11-23 T20):纠错——禁词系统描述、后端存储描述、SDK 埋点描述
> 均按当前实现重写;补 5.1.2(i) AI 数据授权位置说明。

## 1. 内容红线(商店文案 + App 内文案统一口径)

### 禁用词(商店文案/截图/预览视频全适用)

| 禁 | 用 |
|---|---|
| 算命 / 占卜 / 看相 | 八字 / 命理 / 排盘 / 传统文化 |
| 预测 / 预言 / 推算未来 | 结构解读 / 倾向参考 / 自我认知 |
| 灵验 / 准到吓人 / 大师 | 确定性引擎 / 有依据 / 可追溯 |
| 改运 / 转运 / 化解 / 开运 | 调候建议 / 节奏参考(仅健康作息语境) |
| 婚姻注定 / 缘分天定 | 相处模式 / 关系结构 |

### 背书

- 后端有 `forbidden_words` 禁词系统,拦截**绝对化用语**(中文 17 词:必成/必分/必破财/必定/一定会/一定不会/必然/绝对/百分之百/铁定/注定,及繁体形一定會/一定不會/鐵定/絕對/必破財/註定;英文 7 短语:destined to/doomed/guaranteed to/will definitely/will certainly/without a doubt/100%),prompt 模板纪律 + 生成返回与缓存命中**双点扫描**(interpret.py 两处)双防线。**注意**:词表是绝对化用语清单,不含"血光/克夫/大凶/劫难"等词——描述时如实按上表,不要夸大拦截范围(想拦这类词须先改词表,另立任务)。
- 产品页脚已有免责声明文案(医疗/心理/法律/投资),复用到商店描述末尾。

## 2. 中国区特有风险

| 风险 | 应对 |
|---|---|
| 「宣扬封建迷信」驳回 | 全程用「传统文化 + 命理文化 + 自我认知」框架;描述里强调"参考工具,不是判决书";不放八卦图/符咒/香炉类视觉 |
| ICP 备案要求(2023 起中国区强制) | 上架中国区需要 ICP 备案号填入 App 信息。**没有备案则只能先上美区/其他区**——这是排期上最大的前置依赖,需要尽早启动 |
| 个人开发者账号限制 | 确认账号类型;若企业账号,提前准备 DUNS |

## 4. 隐私政策要点(需一个可访问 URL)

内容清单(v0.2 已按实现重写,`tmp/app-store-launch/privacy-policy.md`):
1. 收集什么:出生日期时间/性别/出生地;问事提问原文;合盘称呼;章末反馈(准/不准 + IP 防刷);登录后用户 ID/邮箱
2. 怎么用、去哪里:后端排盘;第三方 AI(Z.ai/DeepSeek)生成解读——发给 AI 的字段逐项列;插画图像服务(按配置启用,prompt 为查表意象);登录后云同步;TelemetryDeck 匿名统计;后端缓存(按内容哈希)、问事记录(问题哈希 + 答案)与章末反馈表(准/不准 + IP 防刷)**均无 TTL 持久保留,删除走联系我们**(待办:自助删除端点)
3. 不做什么:不卖数据、不做广告追踪、不建画像
4. 用户权利:本地数据 App 内重置或卸载即清;服务器侧联系我方
5. 联系方式

> App Store Connect「App 隐私」标签需与隐私政策一致,别写漏。
