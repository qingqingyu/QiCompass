# App Store 商店文案(中国区·草稿 v0.1)

> 逐字段草稿。**红线**(见 review-compliance.md):不用「算命/预测/灵验/改运/大师」,
> 用「传统命理框架 + 自我认知参考」口径——这也是产品真实定位,不是话术规避。

## App 名称(≤30 字符)

**推荐**:玄机问道八字命盘

备选:
- 玄机问道·八字与运势
- QiCompass 玄机问道

> 注:名称里放「八字」搜索权重高;不放「算命」(审核 + 品牌调性双输)。

## 副标题(≤30 字符)

**推荐**:专业八字排盘,看懂自己的运转方式

备选:
- 确定性排盘引擎,AI 只做结构解读
- 不讲吉凶,只讲结构的命理工具

```
把命理当成一面镜子:确定性引擎排盘,结构化解读你的天赋、能量与关系模式。今日运势每天更新,合盘看两个人怎么相处。参考工具,不是判决书。
```

## 描述(≤4000 字符)

```
玄机问道是一款认真的八字工具。它不预测你的命运,而是帮你看清自己的结构。

【为什么它不一样】
• 排盘是确定性的——四柱、十神、藏干、神煞、大运流年,全部由传统历法引擎精确计算,同一时辰永远同一张盘,没有"大师手感"。
• 解读是结构化的——AI 负责把命局翻译成你能读懂的语言:你的十神主线、能量循环、天赋与防御模式,每个判断都标注盘面依据。
• 态度是克制的——不讲吉凶祸福,不给宿命结论,禁止"注定/必然/逃不掉"这类词。命是底盘,运是时机,剩下的取决于你怎么用。

【三大模块】
• 今日运势——每天一句结构化提醒 + 宜忌锚点 + 十二时辰节奏,50 字说清今天怎么过。
• 深度解析——十神结构与命局主线开篇,财运/爱情/健康/六亲/晚年六章展开,200-300 字一章,句句有依据。
• 合盘——两个人不谈"配不配",谈基础相处模式、互补与冲突、未来三年流年同步,给可执行的关系建议。

【设计】
现代东方极简。宣纸白、宋体标题、朱砂点缀。没有黑金奢华,没有恐怖图标,打开是一种安静。

【关于付费】
排盘、今日运势、每章免费试读永久免费。完整深度解析与合盘按命盘解锁(每个命盘一次),无订阅,无广告。

【郑重说明】
本应用基于传统命理框架生成内容,仅供自我觉察与文化参考,不构成医疗、心理、法律或投资建议,不预测具体事件。身体或情绪上的持续困扰,请咨询专业人士。
```
