浏览器里可以真点:
① 在手机画布里往下滚,问事框从 tab 上方滑出(收在顶部 = 不可见);
② 点问事框 → 聊天页向上拉起;点候选问题直接发出,AI 回答;
③ 输入框随便打,有兜底回答;
快捷参数:?cp=1 强制显示问事框,?chat=1 直接开聊天页。

交互口径(对齐你的描述)

  1. 出现时机:今日页收在最上面时问事框不存在;滚到最底才滑出,停在 tab 栏上方——"运势读完"与"可以问事"是同一时刻。
  2. 点击拉起:点问事框,聊天 sheet 向上拉成独立整页,无 tab 栏,顶栏「问事 + 辛未日·比肩 + ✕」。
  3. 开场不空白:登录后第一条消息已在——AI 开场白 + 几条候选问题;点候选问题直接作为你的消息发出,不用打字。
  4. 回答踩盘:AI 回答引用当日盘面(比肩/宜忌/未时冲日支),示例回答是手写的演示文案,非真 LLM。
