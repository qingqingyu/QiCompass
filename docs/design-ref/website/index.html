Signature interactions 新颖但克制

全部服从 DESIGN.md 的动效三式（墨迹晕开 / 落印 / 呼吸），不用视差、不用自动轮播、不做装饰性发光；开启「减少动态效果」时全部降级。

壹时辰盘 Hero

墨圆用 stroke-dashoffset 逐笔画出（2.2 秒），外圈十二地支按本地时间亮起当前时辰，朱点是 DESIGN 允许的「当前时辰点」。

贰排盘晕墨

提交后四柱依次 blur 7→0 显现，间隔 0.3 秒，模拟「布算」的节奏；结果下方的「解」印按 stamp 动效落下。

叁五行生克图

点任意一行：生的关系用墨青实线、克的关系用浓墨实线，其余淡到 14%；右侧释义同步切换，并给出对应专题的内链。

肆术语释义卡

正文里的术语用虚下划线标出，悬停时释义卡墨迹晕开；触屏设备不弹卡，直接跳转（内链优先于提示）。

伍章节墨线

文章左栏的细线随阅读进度从上往下「洇」满，当前章节用朱红聚焦线标出，章号用大写数字。

陆甲子矩阵检索

输入关键词后，不匹配的格子淡出并轻微模糊，命中的格子保持清晰，像在宣纸上圈出要找的那一格。

OG image template 分享卡

1200×630，构建时为每个程序化页面自动生成（Satori 或无头浏览器截图）。版式：左边标题，右边墨圆里放一个大字。
