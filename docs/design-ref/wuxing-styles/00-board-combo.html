组合方向 · 暖白纸底（④）× 气泡能量场（③c）× 数字对比（①c/④b）

同一套数据 · 三个组合姿势，差别在「数字对比」和「气泡场」谁是 hero、版式如何咬合。气泡搬上纸面后改为水淡染 + 细色边的气质。

组合 A · 数字对开 × 纸上气泡场 页首先 84px 对开数字（水 100 vs 火 35），衬线结论句，然后气泡场全宽展开——叙事型，最接近 ④d 的文章感
组合 B · 数字住在气泡里 数字直接长进气泡：水 56px「100」是全场主角，页边细线注记（流日地支/天干），下方「100 vs 35」镜像复述——空间感最强
组合 C · 不对称跨页 左窄栏纵向数字叙事（100 → vs → 35 → 格局结语），右侧气泡群贴栏溢出，下接正文导语——杂志跨页感，信息最紧凑
