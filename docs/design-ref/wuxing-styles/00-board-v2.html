方向 ① Co–Star 式暗黑极简

共同基因：纯黑底 / 白衬线 / 细线网格 / 一点红。变体差在「数据以什么形态出现」。

a · 细线条形版（初稿）2px 横条 + 双栏网格，信息密度均衡
b · 红字陈述版Co–Star 每日推送卡签名式：居中大干支 + 陈述句 + 红标喜用
c · 数字网格版合盘页式：88px 巨型数字对比 100 vs 35，五行五格纯数字
d · 纯文字流版运势 feed 式：几乎零图形，五行内嵌一行，时辰一句话竖排串
方向 ③ 柔彩显化系

共同基因：软渐变 / 大圆角卡 / 肯定语气 / 徽章化喜忌。变体差在五行力量的主 viz。

a · 能量条版（初稿）渐变横条 + 喜/忌徽章，最稳
b · 圆环仪表版五枚 conic-gradient 圆环，青绿薄荷色系，Calm 感
c · 能量气泡版气泡大小 ∝ 五行力量，漂浮在渐变网格上，最有「能量场」感
d · 横滑元素卡版Me+ 习惯卡式横滑 deck + 时辰纵向时间轴
方向 ④ 浅色编辑排版

共同基因：米白底 / 衬线 / 报刊留白 / 克制配色。变体差在「报刊的哪种版式」。
