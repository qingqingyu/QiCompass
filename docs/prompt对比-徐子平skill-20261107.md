## 12 子维裁决矩阵

裁决三档:**他优 / 我优 / 取向不同**。每子维先按各自产品目标评达成度,再给裁决;「无条件优势」= 不依赖产品立场也成立的点。

### A 组:命理方法论(他优 3 / 取向不同 2)

#### A1 旺衰判定 — **他优**

- 各自达成度:双方都在自身哲学内自洽——他要「可解释的传统命理证据链」,我们要「确定性纯函数,同输入同输出」。
- 依据:
  - 他:`paipan.py:160-200` 月令按十神分档计分(比劫+3.0/印+2.0/食伤-1.75/财-1.25/官杀-2.5),**通根查全部四柱**且按藏干层次加权(本气 1.75/中气 1.0/余气 0.5),天干生扶带**位置因子**(年 0.8/月 1.2/时 1.0);输出候选+置信度(`sample_output.txt:32`)。`README.md:76` 引《滴天髓》「得令未必必旺」,哲学落进了代码。
  - 我:`xiji.py:126-156` 得令二值(+5 或 0),**得地只算日支**(`xiji.py:140-149`),无位置因子;`xiji.py:28-43` 权重阈值自称「初值,待 50 盘 spike 标定」。
- 裁决理由:证据覆盖面(全柱通根/月令分档/位置因子)客观更全,这不是立场问题。注:双方权重魔数都未经大盘标定,打分公式精细 ≠ 结论更准,此维度裁的是「证据面」。
- 无条件优势(他):置信度透传给叙事层。我方有意不给数字(`chart_builder.py:76-79` `strength_score: None`,注释「留 None…而非误导性的数字」)——这是拍板过的取向,但意味着 LLM 只见一个词。

#### A2 喜用口径 — **他优**

- 依据:
  - 他:`paipan.py:376-414` 格局用神/扶抑喜神/调候**三口径分列**,每项带理由;扶抑理由含**通关**概念(`paipan.py:390`「印星通关官杀并生身」——官杀压力大时印 simultaneously 化杀生身);中和特例「优先围绕格局成败取用」(`paipan.py:396`);调候按季(夏水冬火,春秋「不设机械调候单字,结合寒暖燥湿复核」);`sample_output.txt:45`「三种口径不强行合并成唯一用神」。
  - 我:`xiji.py:297-320` 扶抑+调候**合成单一** favorable 列表(调候命中时从忌神移除并插入首位,`xiji.py:206-211` 冲突处理是细心的,但口径来源在最终列表里不可见);调候仅覆盖 4 个月(子丑喜火/午未喜水,`xiji.py:23-26`);deep 链 chart 只给 `useful_god_candidates` 裸五行(`chart_builder.py:110-114`),LLM 讲不出「为什么喜水」。
- 裁决理由:用神分层(格局/扶抑/调候)是子平传统里真实的方法论层次,合并有信息损失。
- 无条件优势(我):**从格诚实降级**——`xiji.py:264-278` 从格/专旺命中即清空喜忌;对方 `analyze_use_gods` **无从格分支**(status 只有偏弱/偏旺/中和三路,`paipan.py:386-396`),专旺特征盘照样机械输出扶抑喜神,特殊格局复核只是格局层的标注——这在命理上是自相矛盾的输出。

#### A3 格局处理 — **取向不同**

- 依据:
  - 他:`paipan.py:254-337` 月令藏干+透干 → 格局候选(正官格/伤官格)+置信度+特殊格局复核(乙庚合化金候选,`sample_output.txt:39`);`SKILL.md:54`「不得擅自装成唯一结论」。
  - 我:ADR-0006 砍掉格局判定;M0 v7 起「格」结尾词入禁词表且补齐复合格名(杀印相生格等,`prompts.py:142-144`);产品话术是「命局呈现××倾向」。
- 裁决理由:双尺子下各自成立——传统命理体验里格局是子平法骨架,砍掉就不成体系;现代自我认知工具里「正官格」是黑话,去格局是产品决策。
- 无条件小优势(他):「候选+置信度而非断言」这套技术在任何框架下都是防 LLM 越权的通用武器;我们的对应物是「倾向叙事+禁格名」,只防了输出端。

#### A4 合冲刑害的叙事使用 — **他优**(限 deep 单盘解读信息面)

- 依据:
  - 他:`paipan.py:339-374` 客观列出三合三会六合六冲刑害,「是否成化留给格局层判断」;`SKILL.md:57` 结合合冲刑会断成败救应;`sample_output.txt:31` 巳午未三会火方进旺衰证据链。
  - 我:`branch_relations.py` 引擎**已算全部地支关系**(合盘模块消费,判定序已到 v2),但 deep 链 chart **无任何地支关系字段**(`chart_builder.py` 输出清单里没有);`prompts.py:615` 禁的是「刑冲破害的**凶险叙事**」,不是数据本身。
- 裁决理由:合会冲是命局结构的客观事实,他们喂给 LLM,我们只在合盘喂。这是「引擎有数据、deep 链没接」的现成能力缺口,不是设计取舍。

#### A5 大运流年深度 — **取向不同**(含他方无条件子项优势)

- 依据:
  - 他:八步大运**每步标注运神十神**(`sample_output.txt:51` 壬午(正印)…);`SKILL.md:58`「断何时必指某步大运、某个流年干支,说明生克刑冲合会」;流年就近三五年逐年点用忌。
  - 我:luck_pillars 只有 start_age/stem/branch,无运神(`chart_builder.py:123-127`);current_luck.ten_god=None **让 LLM 自推**(`chart_builder.py:152-155`,注释自称「LLM 命理基础知识 100% 准确算」——但 `prompts.py:204` 记录过 LLM 把藏干十神认错的前科,此注释与自家教训相抵);时间断言被 v10 括注约束(`prompts.py:689-693`),_V1 禁预测时间点(`prompts.py:616`)。
- 裁决理由:敢断应期 vs 刻意不断应期,是产品哲学之差(命理传统价值 vs 不制造不可验证的期待),双方各自达成。
- 无条件优势(他):**运神确定性标注**。让 LLM 自推十神恰好踩在我们自己记录过的概率翻车面上,这是纯缺陷修补,不涉立场。

### B 组:解读质量(我优 3 / 取向不同 1)

#### B6 证据纪律/防幻觉 — **我优**(无条件)

- 依据:
  - 他:`SKILL.md:18` 一句话人设级约束「每一句断语,皆能回指到命盘中某一干支、某一十神、某一生克」+ 方法论五步。零检验机制,全凭模型自觉。
  - 我:evidence 字段 schema 强制;机器字段名禁用清单(`prompts.py:647`);十神藏干归属照表引用纪律(`prompts.py:650`);防抄示例短语表 `M0_V9_EXAMPLE_PHRASES`(`prompts.py:759-771`);三层写法数字只进据(`prompts.py:674`);evalkit L1 判据离线回归 160 条(CLAUDE.md 守护栏)。evalkit 实战抓过真实翻车(权重并列/藏干归属/从格编造喜忌,`docs/命书M0主线结构内容质量修复-plan.md:170`)。
- 注记(他方优点):整套纪律我们花约 7000+ prompt token + evalkit 基建;他 2 行。对一次性对话产品这是成本差;但我们的纪律防住了真实事故,投入有实证回报。

#### B7 诚实降级 — **我优**(机制深度;他方有粒度优点)

- 依据:
  - 他:低置信度保留意见(`SKILL.md:53`)、时柱存疑声明(`SKILL.md:40`)、格局候选不装唯一(`SKILL.md:54`)——全部是指令层。
  - 我:从格诚实告知条款(`prompts.py:156-158`);时辰未知走**降级模板变体,喜忌栏与 12 时辰段整体不进 prompt**——「不是靠指令压制,数据块不进 prompt」(`prompts.py:29-30`);排盘歧义柱置 null 不猜(`bazi_engine.py:163-171`);unknown_hour 喜忌不硬算(`xiji.py:235-255`「可靠性无法验证就不给」)。
- 裁决理由:数据面降级(不给 LLM 诱惑)比指令面降级(叫 LLM 别说)彻底,这是 S09 拍板结论,对方没做到这一层。
- 无条件优势(他):置信度**连续档**(中/低)粒度细于我们的三态(正常/special/unknown);他们的旺衰候选天然带「保留意见」表达位。

#### B8 白话可达性 — **我优**(无条件)

- 依据:
  - 他:「多用术语但随即白话点破」一句话(`SKILL.md:68`),无表无判据。
  - 我:三层写法(白话结论 ≤25 字外行能懂/展开/据,`prompts.py:673-674`);十神白话释义**固定表**(`prompts.py:675-687`);大运白话化「约 X 岁起的那十年」(`prompts.py:689`);结论/展开层禁工程腔词表(`prompts.py:696`);evalkit 判据锁定;v9-v11 三轮真机截图驱动迭代(`prompts.py:169-199` 版本史)。
- 裁决理由:定义密度、检验闭环、迭代轮次全面领先。

#### B9 口吻人设 — **取向不同**

- 依据:他:徐子平沉浸式古典半白,「吾观此造」(`SKILL.md:16,68`),权威感即产品价值;我:「命理结构分析师,不是算命先生」(`prompts.py:603`),对齐 DESIGN.md「专业不忽悠,不像算命软件」。
- 裁决理由:各自目标下都达成,无无条件优劣。
- 组级观察:他们的人设风格一次成型;我们的 voice 从 v2 Medium 走到 v11 三层写法迭代了十余轮——说明「现代白话且不忽悠」比「古典腔」难写得多,这是我们的隐性投入壁垒。

### C 组:内容覆盖(取向不同 2)

#### C10 板块覆盖 — **取向不同**(他覆盖付费刚需空白)

- 依据:他:事业财运/家庭婚姻/健康性格流年/子女(`SKILL.md:59-64`),男命财星为妻/女命官杀为夫/时柱子息宫,传统命理四大问全覆盖;我:M0-M7(主线/天赋/高低配/人生系统/健康/财富/动力学/落地手册,`prompts.py:200-223`)+每日+合盘+问事,无婚恋无子女。
- 裁决理由:他要「命理用户最想问的」,我们要「自我认知用户最需要的」,各自达成。
- 事实注记:婚恋/子女是命理付费用户的高频刚需,我们 v1 刻意不含(v2+ 范围);行动导向(M7 90 天手册)他们完全没有——互有独占板块,故取向不同。健康板块双方都有且边界声明都到位(他 `SKILL.md:72` 不替代医嘱;我 `prompts.py:617` 不做医学诊断)。

#### C11 时间断言边界 — **取向不同**

- 依据:他:应期是核心交付,三五年逐年点(`SKILL.md:58,63`);我:禁预测具体事件/时间点(`prompts.py:616`),大运只作「何时会变」的条件观察(v10 括注,`prompts.py:689-693`)。
- 裁决理由:传统价值(敢说何时才显得准) vs 产品安全(不可验证的预测制造焦虑)——真·世界观差异,不可比优劣。

### D 组:工程化(我优 1)

#### D12 排盘保障/测试/缓存/付费/回归 — **我优**(无条件,量级差)

- 依据:我:双层缓存按 (content_hash, module, prompt_version) 失效;context_token 五族签发-验签防伪;付费墙 SKU 双端同步守护栏;evalkit 160 判据回归 + BASELINE;三语模板;免费/付费/退款三重配额;LLM 失败率告警。他:单文件 MIT,无缓存无评测无多语言。

## 组级小结

| 组 | 他优 | 我优 | 取向不同 | 一句话 |
|---|---|---|---|---|
| A 命理方法论 | **3** | 0 | 2 | 他拿下方法论大头——这正是借鉴价值所在 |

最锋利的一句话:**他们的优点集中在「引擎给 LLM 喂什么命理事实」,我们的优点集中在「LLM 拿到事实后怎么被管住」**——两条正交轴,所以借鉴清单几乎不与我们的既有优势冲突。

## 借鉴清单(按性价比排序;实施与否逐项另拍)

### ① 大运运神十神确定性标注【性价比最高】

- 借鉴点:luck_pillars / current_luck 加确定性十神标注(对方 `sample_output.txt:51` 每步运标注运神;我们 `chart_builder.py:152-155` 现状 ten_god=None 让 LLM 自推)。
- 撞拍板:**不撞**。反而修复自家记录过的翻车面(`prompts.py:204` LLM 藏干十神认错前科,注释「100% 准确算」与该教训相抵)。
- 成本:**低**。十神推演逻辑 pillars.py 已有(compute_ten_god_weights 同源);chart_builder 加字段 + 模板措辞 + 三语 bump + evalkit 一轮。
- 收益:**高**。M0 leak「何时会变」可落到「那步运是印运」;消除一类 LLM 概率错误;从格盘大运观察句更稳。

### ② 地支关系进 deep chart

- 借鉴点:chart JSON 加合冲刑害客观清单(对方 `paipan.py:339-374` 先例:「客观列出,是否成化留给判断层」)。
- 撞拍板:**轻碰不推翻**。`prompts.py:615` 禁「凶险叙事」——地支关系作**结构解释**使用(如三会火方→火力集中)不违反禁令,但模板措辞须专门设计,防 LLM 滑向吉凶。
- 成本:**低-中**。branch_relations.py 判定现成(合盘 v2 判定序),只差接进 chart_builder + 模板三语 bump + evalkit。
- 收益:**中-高**。deep 链目前完全看不见地支之间的结构,这是引擎有数据没接的缺口。

### ③ 喜用口径分层:扶抑/调候分列 + 各带理由

- 借鉴点:useful_god_candidates 从裸五行列表改为带口径来源与理由(对方 `paipan.py:376-414` 先例,含「印星通关官杀并生身」式理由;我们 `xiji.py:206-211` 的调候冲突处理已具备分列的内部信息,只是最终列表把它抹掉了)。
- 撞拍板:**不撞**「确定性规则引擎」决策(分层仍是确定性);决策 1 的表述微调。
- 成本:**中**。XijiResult 结构改 + chart 字段 + 模板教 LLM 讲「为什么喜」+ 三语 bump + evalkit。顺带可议:调候覆盖从 4 个月扩到季节级(对方粒度)。
- 收益:**中**。「冬令寒局故喜火」比裸「喜水」可讲得多;从格条款不受影响。

### ④ 旺衰证据面扩充:全柱通根 + 月令分档

- 借鉴点:扶抑打分从「得令二值 + 仅日支得地」扩到「月令按十神分档 + 全柱通根分层加权」(对方 `paipan.py:160-200` 先例)。
- 撞拍板:**不推翻但触发联动**。calc rule 有版本快照通道(calc_rule_snapshot);喜忌结论会变 → 按合盘先例走「引擎规则版本 × prompt 版本联动」;50 盘标定本来是待办事项。
- 成本:**中-高**。公式改 + 阈值重标定 + 重对盘(问真抽样)+ 联动 bump。置信度透传若一并做,须尊重「不给误导性数字」的既有拍板(`chart_builder.py:76-79`),宜用档位词不用裸分。
- 收益:**中**。月令非比劫/印的盘(食伤/财/官杀当令)现在丢分档信息;准确度收益真实,但标定工作量真,不宜急。

### ⑤ 婚恋/子女板块【需先拍世界观,不是借鉴是产品决策】

- 借鉴点:对方四大板块里的家庭婚姻/子女(`SKILL.md:61-64`)是命理付费用户高频刚需,我们完全空白。
- 撞拍板:**撞两条**——v1 三模块范围(「不做的事」清单未列婚恋,但 v1 无此内容)+ `prompts.py:617`「不断言婚姻」。「财星为妻/官杀为夫」式断语与我们的世界观约束需要重新设计才能共存。
- 成本:**高**(新模块+付费墙+措辞体系)。
- 收益:**高**(付费面)。结论:单独立项拍板,本清单只登记不排期。

### ⑥ 置信度/保留意见透传【低优先】

- 借鉴点:旺衰候选带置信档,LLM 可写「中等把握」。
- 撞拍板:碰「确定性哲学」表述——我们的 special/unknown 三态已是离散置信,加连续档要拍「要不要让用户看见不确定性」。
- 成本:低;收益:低-中。排在最后。
