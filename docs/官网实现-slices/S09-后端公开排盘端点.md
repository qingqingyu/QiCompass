# S09 后端公开排盘端点 `/api/public/chart`

- **类型**: AFK
- **Blocked by**: 无 —— 可与一期并行开发;**上线**依赖后端生产部署(部署决策 S4)
- **覆盖决策**: `docs/SEO站设计决策.md` #4(公开只读端点:不签 context_token、不碰 LLM、IP 限流、CORS 仅放行站点域名)
- **Parent**: `docs/官网实现-slices/README.md`

## What to build

1. **路由** `backend/app/api/public_chart.py`,在 `app/main.py` 注册:`GET /api/public/chart?d=YYYY-MM-DD&t=HH:MM&tz=…&lon=…&lat=…&g=m|f&hk=true|false`(GET 便于 CDN 缓存;也可 POST,二选一写进规格并告知用户)
2. **复用排盘核心**:与 `POST /api/bazi/calculate`(`backend/app/api/bazi.py`)共用同一套计算函数(抽共享函数,**禁止复制粘贴**),保证网站与 App **同盘**;强制 `setSect(1)`;时辰未知走现有 `hour_known` 路径
3. **响应裁剪**:只返回网站展示需要的字段 —— 四柱(干支 / 十神 / 藏干 / 纳音 / 长生)、五行计数、旺衰 label、喜忌(从格时留空 + `special_pattern`)、大运(跳过 index=0 童限)、神煞、真太阳时修正量、使用的规则(`zi_hour_rule` 等)。**不返回** `content_hash`、任何 `context_token`、任何 prompt 相关字段
4. **不签 token、不调 LLM、不写库**(不落任何出生数据;日志里出生时间只记到小时粒度或不记)
5. **限流**:按 IP,默认 30 次 / 分钟、500 次 / 天(环境变量可调,写进 `backend/.env.example`);超限 429,用 `app/errors.py` 现有的结构化错误
6. **CORS**:只放行 `https://knowfate.app`(及本地开发 `http://localhost:4321`,通过环境变量);其他 Origin 不返回 CORS 头
7. **缓存头**:同参数结果确定,返回 `Cache-Control: public, max-age=86400`
