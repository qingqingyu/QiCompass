# S03 知识页模板 + 甲木样张

- **类型**: AFK
- **Blocked by**: S02
- **覆盖规格**: `design-ref/website/README.md` §4.3、§5、§7、§10(释义卡 / 章节墨线 / 吸底条)
- **视觉稿**: `docs/design-ref/website/article.html`
- **Parent**: `docs/官网实现-slices/README.md`

## What to build

1. **`ArticleLayout.astro`**,所有程序化知识页共用,区块顺序严格按规格 §4.3 的骨架:
   面包屑 → Hero(Enso + 大字五行色 + 落印 / kicker / H1 / 副题 / 署名行 / 竖排题签)→ 三栏(左 TOC 章节轨 / 正文 ≤680px / 右栏 sticky)→ In short 答案框 → 速查表 → H2 编号章节 → 内联 CTA(第 2 个 H2 之后自动插入)→ FAQ → 「批」印收束 → 文末 CTA 面板 → 上一篇 / 下一篇 → 出处与方法 → 免责
2. **组件**:`AnswerBox`、`Facts`、`Toc`(含墨线进度、朱红聚焦线、scrollspy)、`TermLink`(释义卡:仅 `(hover: hover)` 设备弹出,触屏直接跳转)、`CtaInline`、`CtaPanel`、`StickyCta`(答案框滚出视口后出现,接近 footer 隐藏,关闭写 sessionStorage 且读写都包 try/catch)、`NeighborsNav`、`FaqList`(`<details>`)
3. **CTA 文案按页面类型参数化**(日主页「Is your Day Master Jia?」→ 排盘器;十神页 / 神煞页「Does your chart have …?」),所有 CTA 链接带归因参数 `?ct={type}-{slug}-{slot}`(slot = inline / end / sticky / rail)
4. **一期状态**:`features.calculator=off` 时,CTA 目标改为 Library 或邮箱表单(见规格 §12 分期表);右栏日主查询小工具换成「十日主速查」列表
5. **JSON-LD**:`Article`(`dateModified`、`citation`、`about: DefinedTerm`)+ `BreadcrumbList` + `FAQPage`(与页面上的 FAQ 逐字一致,由同一份 frontmatter 生成)
6. **样张**:`/en/day-master/jia-wood`,内容照搬 `article.html` 的文字(已按红线写好),走完整的 content collection → 模板 → 校验流程

## Acceptance criteria

- [ ] 样张与 `article.html` 在 1440 / 390 两种宽度下视觉一致(截图并排附在报告里)
- [ ] 关 JS 可读;TOC、释义卡、吸底条在关 JS 时退化为普通目录 / 链接 / 不显示
- [ ] Google Rich Results Test(或 schema.org validator)对样张的 JSON-LD 无错误
- [ ] `check_site_content.py` PASS;页面正文内链 ≥ 8 条
- [ ] 吸底条:页面顶部不显示,滚过答案框后显示,接近 footer 隐藏,关闭后同会话不再出现
- [ ] Lighthouse 移动端:Performance ≥ 95,CLS < 0.02
- [ ] 换一份十神页的测试 frontmatter,模板不改代码即可渲染(证明模板通用)

## 实现锚点

- 交互参考 `assets/site.js`:popover(释义卡)、TOC scrollspy + progress、sticky CTA 的实现逻辑可直接改写
- 样式参考 `article.html` 页内 `<style>`,改为组件作用域样式

## 红线与约束

- 「In short」必须是一句完整定义句(争取精选摘要),≤60 词,不能写成营销语
- 朱红只用于 TOC 聚焦线与印章;CTA 按钮一律焦墨底
- 不在模板里写死任何日主 / 十神具体内容,全部来自 content 与 `terms.json`
