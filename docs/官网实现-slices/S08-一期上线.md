## What to do

实现方 AI 负责**准备**:写好每一步的操作清单、配置文件、验证命令;用户负责在自己的账号里点按钮。每完成一步,用户回报,AI 验证后再进行下一步。

1. **Cloudflare Pages 项目**:连接 GitHub 仓库,构建命令 `cd site && npm ci && npm run build`,输出目录 `site/dist`;生产分支由用户指定
2. **域名**:`knowfate.app` 根域指向 Pages(Pages 自带 CDN,**橙云 OK**);`www` 301 到根域。⚠️ **`api.knowfate.app` 必须保持灰云**(部署决策 C3,不过 CDN 代理),不要动它
3. **每日重建**:Pages Deploy Hook + Cloudflare Cron Trigger(或 GitHub 定时任务)每天 UTC+8 00:05 触发一次构建,刷新「今日」数据
4. **邮箱**:Cloudflare Email Routing 建 `hello@knowfate.app` → 用户私人邮箱;发一封测试信验证
5. **Search Console**:域名资源验证(DNS TXT)→ 提交 `sitemap-index.xml` → 对首页、排盘器页、甲木页「请求编入索引」
6. **Bing Webmaster Tools**:从 Search Console 导入(同时覆盖 ChatGPT / Copilot 的搜索来源)
