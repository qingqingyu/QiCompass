## 2. 逐条详情

### F1　豁免配额重生成仍退次数

**位置**：`ios/QiCompass/QiCompass/Services/DeepAnalysisOrchestrator.swift` `runV1Module`，约 `:316-354`

**现状**：

```swift
var shouldRefundOnFailure = false
if quotaExempt {
    // 不扣次数
} else {
    shouldRefundOnFailure = true
    guard counter.tryConsume(module: counterModule) else { ... }
}
...
if resp.cached {
    counter.refund(module: counterModule)   // ← 不看 quotaExempt
    shouldRefundOnFailure = false
}
```

**触发**：L4 STALE_SOURCE 降级重生成（`quotaExempt == true`）→ 后端 SQLite 缓存命中 `resp.cached == true` → `refund` 一次。没扣过却退了，每章 +1 次，一张盘最多 +8。

**修法**：`if resp.cached && !quotaExempt { ... }`（或统一用"是否实际扣过"的布尔判断 refund，扣过才退）。

**测试**：`quotaExempt: true` + mock `interpret` 返回 `cached: true` → 断言 counter 剩余次数不变；`quotaExempt: false` + cached → 仍退 1 次（原行为不回归）。

### F2　深度解析：自动翻译失败后换盘回来卡死

**位置**：`ios/QiCompass/QiCompass/Features/DeepAnalysis/DeepAnalysisViewModel.swift`
- 换盘清洗：`loadArchivedChart` 约 `:555-568`（`translationOffer = nil` / `crossLanguageRows.removeAll()` / `autoTranslationState = nil`）
- 自动翻译去重：`autoTranslateIfNeeded` 约 `:640-652`（`autoTranslationAttemptedKeys` 按 `contentHash|lang` 会话去重）
- 提示条判定：`DeepAnalysisHomeView.swift` `translateHintBarMode` 约 `:40-55`——**要求 `autoTranslationState != nil`** 才渲染
- 续跑守卫：`resumeV1ChainIfNeeded` 在 `translationOffer != nil` 时被 `translation_pending` 拦住

**复现路径**：
1. 盘 A 有跨语言原文 → 打开自动翻译 → 失败（`autoTranslationState = .failed`，提示条显示"部分章节翻译失败"+重试）。
2. 切到盘 B → 清洗把 `autoTranslationState` 置 nil。
3. 切回盘 A → hydrate 重新算出 `translationOffer`（非 nil）→ `autoTranslateIfNeeded` 因 key 已在 `autoTranslationAttemptedKeys` 跳过 → `autoTranslationState` 仍为 nil → **提示条不渲染**；同时 offer 非 nil → **续跑被拦**。
4. 结果：缺失章不生成、已有原文不翻译、无任何重试入口。

**修法（二选一，推荐 A）**：
- **A**：`autoTranslateIfNeeded` 在去重命中（已尝试过）时，不是直接 return，而是把 `autoTranslationState = .failed`，让提示条以"手动重试"形态出现（保持"失败后不自动重试、防烧 LLM"的语义）。
- **B**：在 VM 层按 key 记住失败态（`[key: AutoTranslationDisplay]`），换盘回来恢复。

**测试**：扩展 `TranslationFlowTests`——A 盘翻译失败 → 切 B → 切回 A → 断言 `translationOffer != nil` 时 `autoTranslationState == .failed`（或提示条 mode 非 nil）。

### F3　合盘：自动翻译失败后重开该对卡死

**位置**：`ios/QiCompass/QiCompass/Features/Compatibility/CompatibilityViewModel.swift`
- `openDetail` 约 `:1728-1733`：`translationOffer = nil; translationFailed = false`
- 跨语言命中后 `autoTranslateCrossLanguageIfIdle` 约 `:1846-1857`：按 `compatibilityHash|lang` 会话去重
- 提示条：`CompatibilityMainView.swift:64` `if let offer = vm.translationOffer, vm.translationFailed`
- #13 已拔除手动生成按钮（自动起链），且跨语言命中时 `interpretState` 已是 `.okFree/.okPaid(旧语言原文)`，`autoGenerateInterpretationIfIdle` 因非 `.idle` 不触发

**复现路径**：自动翻译失败 → 返回列表 → 重开同一对 → `translationFailed` 被清为 false、offer 重新挂上 → 自动翻译被去重跳过 → 提示条因 `translationFailed == false` 不出现 → 页面停在旧语言原文，无重试、无生成。

**修法**：与 F2 同构——去重命中时置 `translationFailed = true`（让提示条以重试形态出现），不再静默 return。

**测试**：扩展 `CompatibilityViewModelBatchTests`（或新增用例到翻译相关测试）——首次翻译失败 → 重开 detail → 断言 `translationOffer != nil && translationFailed == true`。

### F4　每日运势：翻译失败无降级

**位置**：`ios/QiCompass/QiCompass/Services/DailyFortuneOrchestrator.swift`
- 分支选择 约 `:176-189`：有跨语言源 → `return try await translateExisting(...)`
- `translateExisting` 约 `:330-400`：失败直接 throw，不回落

**问题**：深度解析的 L4 已把 STALE_SOURCE（原文版本过期 / 后端清库后原文不可核验，后端返回 409）降级为目标语言重生成；每日运势没有。prompt bump 或后端换库后，每次进入都走同一个必败翻译，当天新语言解读永远出不来（每日页只会显示引擎模板降级文案）。

**修法**：
- `translateExisting` 捕获 **STALE_SOURCE**（判定可复用/镜像 `DeepAnalysisViewModel.isStaleSourceError`，约 `:1413`）（以及"译文契约校验失败" `translatedContentInvalid`，可选）→ 记 warning 日志 → 落穿到下方正常生成路径（第 3 步次数检查 + 生成）。
- **注意计费口径**：L5 拍板"切语言改翻译、不扣次数"。降级生成是否扣次数需与深度解析 L4 对齐（L4 是豁免配额）。建议同样豁免：给生成路径加 `quotaExempt` 参数，豁免时跳过 `tryConsume`，且 **cached 命中不 refund**（别重蹈 F1）。
- 网络类错误（离线）**不**降级，照旧抛出（避免离线时误扣/误生成）。

**测试**：扩展 `DailyFortuneFailureFallbackTests`——mock `translate` 抛 STALE_SOURCE → 断言调用了 `interpret` 且计数不变（豁免）；mock 抛网络错误 → 断言不调用 `interpret`、错误上抛。

### F5　M0 降级重生成标记不跨重试

**位置**：`ios/QiCompass/QiCompass/Features/DeepAnalysis/DeepAnalysisViewModel.swift` `runTranslationChain` 约 `:1238-1245`

```swift
var staleM0Downgraded = false   // ← 局部变量，每次进链重置
var staleRegenFailed = false
```

**问题**：M0 原文 STALE → M0 已按目标语言重生成 → 下游某章降级重生成失败（`staleRegenFailed`）→ 用户点重试 → 重新进 `runTranslationChain`，`staleM0Downgraded` 回到 false，且 M0 已不在 `crossLanguageRows` 中 → 剩下基于**旧 M0** 的下游原文被拿去**翻译**，与新 M0 叙事矛盾（翻译请求的链字段来自新 M0，缓存键也对不齐）。

**修法**：把该标记提升为 VM 实例状态（如 `private var staleM0DowngradedHashes: Set<String>` 按 `contentHash|targetLang` 记），在 offer 清空 / 换盘 / 全部完成时清除；`runTranslationChain` 入口读取它初始化局部变量。

**测试**：M0 STALE 降级成功 + M2 降级失败 → 调重试 → 断言 M2 走 `interpret`（重生成）而非 `translate`。
