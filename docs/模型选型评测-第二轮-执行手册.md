## 0. 为什么有第二轮

第一轮只比了 GLM 与 DeepSeek,主要量的是稳定性和速度(JSON 坏没坏、禁词、延迟)。用户真正在意的三件事,第一轮基本没量到:

1. **读起来像懂我**:读的人有没有「它怎么知道」的感觉,而不是套话。**这只有真人读自己的命盘才能判断**,评测机里的 20 个历史盘没人能代入。
2. **命理专业度**:懂行的人看了不挑刺。第一轮的 L3 裁判评分表是为旧版深度解析写的,和 v1 模块对不上,分数不可靠。
3. **英文给外国人读**:读起来自然,不像翻译腔。

另外,第一轮没有测国外模型。本轮加入 **Claude / GPT / Gemini**,与 GLM、DeepSeek 一共 5 个模型同台比较。

本轮的三条评测线:

| 线 | 量什么 | 谁来评 | 数据去向 |
|---|---|---|---|
| A 机器线 | 稳定性、红线违规、延迟(新 3 个模型补跑,GLM/DeepSeek 复用第一轮) | 脚本 `summarize.py` | 推送 |
| B 专家盲评线 | 命理专业度 + 英文质量 | 评审者(Claude),**盲评** | 盲评包推送,**映射表封存** |
| C 真人线 | 「像不像我」 | 用户本人 + 3-4 位知情同意的亲友,**盲评** | **全部只留本机**,只推送匿名打分表 |

**为什么要盲评**:评审者 Claude 本身是 Anthropic 的模型,而 Claude 也是候选之一。盲评(每个条目独立随机打乱 A-E 字母,映射表在评审交卷前不公开)是为了防止评审偏向自家模型。真人线同理,避免「听说是 GPT 写的所以更好」。

## 1. 硬性规则(违反任一条 = 本次结果作废)

第一轮的 6 条继续有效:不改仓库代码与模板 / 不设基线 / 不提交密钥 / 不合并到 main / 如实报告 / 网络层失败同一条最多补跑一次。本轮新增:

7. **不跑 L3 裁判**:所有新 run 一律加 `--skip-judge`。第一轮已证明评分表与 v1 模块不匹配,而且 Claude 本轮是候选,再用 Claude 当裁判会有利益冲突。
8. **映射表封存**:`SEALED_*.json` 只存在本机 `~/qc-eval/`,**在用户明确说「评审已交卷,可以公开」之前不得推送、不得贴进任何报告或聊天**。
9. **真人数据不出本机**:真人的出生信息(`persons.json`)、真人命盘的 prompt 与输出、真人盲评包,**一律不进 git、不推送**。只推送匿名打分表(人用 P1/P2 代称)。
10. **执行者不读盲评内容做判断**:不要在报告里评论哪个版本好。你的工作是生成包、守住封存。
11. **汇总只用脚本**:§4 的数字全部由 `summarize.py` 产出、原样贴进报告,**不要手算或改写**(第一轮手工汇总漏掉了 GLM 的 4 条喜忌违规)。

## 7. 评审者会看什么

- **专家盲评包**:对每个条目的 5 个版本按「命理专业度」排序(十神解读是否准确、是否守住后端喜忌、从格盘是否诚实、有无编造);英文条目额外评「外国读者读起来是否自然」。评审结论**在看到映射表之前**提交到分支
- **机器汇总**:生产首调失败率、红线违规、延迟,作为一票否决项(例如首调失败率显著偏高的模型,再好看也不推荐)
- **真人打分**:「像我」分数与排序,这是本轮权重最高的信号。样本小(3-5 人),评审会按人逐个看,不只看平均

### `~/qc-eval/summarize.py`

```python
"""机器汇总(仓库外临时脚本)。用法:
python ~/qc-eval/summarize.py GLM=<run_dir> DeepSeek=<run_dir> Claude=<run_dir> ...
输出 Markdown 到 stdout。所有口径写死在这里,执行者不要手算。"""
import collections
import json
import re
import statistics
import sys
from pathlib import Path

RED_LINES = ("喜忌矛盾", "编造喜忌", "地支五行错置", "硬性格局")


def cat(text: str) -> str:
    return re.split(r"[:：(]", text, maxsplit=1)[0].strip()


def load(run_dir: Path):
    rows = [json.loads(l) for l in (run_dir / "results.jsonl").read_text(encoding="utf-8").splitlines() if l.strip()]
    meta = json.loads((run_dir / "meta.json").read_text(encoding="utf-8"))
    return rows, meta


def analyze(rows):
    s = collections.Counter()
    cats = collections.Counter()
    red = collections.Counter()
    lat = []
    for r in rows:
        err = r.get("error") or ""
        fails = [f for layer in ("l1", "l2") for f in ((r.get(layer) or {}).get("failures") or [])]
        for f in fails:
            cats[cat(f)] += 1
            for k in RED_LINES:
                if k in cat(f):
                    red[k] += 1
        if err:
            cats["ERROR:" + cat(err)] += 1
        cascade = err.startswith("链路中断") or "prompt 渲染缺字段" in err
        if cascade:
            s["cascade"] += 1
            continue
        s["attempted"] += 1
        if any("JSON 解析失败" in f for f in fails):
            s["json_fail"] += 1
        elif any(f.startswith("生产禁词命中") for f in fails):
            s["forbidden"] += 1
        elif err and not err.startswith("裁判失败"):
            s["gen_error"] += 1
        if r.get("elapsed_ms") and not r.get("cached"):
            lat.append(r["elapsed_ms"] / 1000)
    s["prod_fail"] = s["json_fail"] + s["forbidden"] + s["gen_error"]
    return s, cats, red, lat


def pct(a, b):
    return f"{a}/{b}({a / b:.0%})" if b else "—"


def q(lat, p):
    if not lat:
        return "—"
    lat = sorted(lat)
    return f"{lat[min(len(lat) - 1, int(round(p * (len(lat) - 1))))]:.1f}"


def main():
    runs = []
    for arg in sys.argv[1:]:
        label, _, path = arg.partition("=")
        rows, meta = load(Path(path))
        runs.append((label, rows, meta, *analyze(rows)))
    pv = {json.dumps(m.get("identity", {}).get("prompt_versions"), sort_keys=True) for _, _, m, *_ in runs}
    print(f"prompt_versions 一致:{'是' if len(pv) == 1 else '否 !!! ' + ' | '.join(pv)}\n")
    print("| 指标 | " + " | ".join(l for l, *_ in runs) + " |")
    print("|---|" + "---|" * len(runs))
    def row(name, fn):
        print(f"| {name} | " + " | ".join(fn(x) for x in runs) + " |")
    row("模型身份(meta)", lambda x: f"{x[2].get('identity', {}).get('provider')}/{x[2].get('identity', {}).get('model')}")
    row("verdict 分布 pass/warn/fail/error", lambda x: "/".join(str(collections.Counter(r['verdict'] for r in x[1])[k]) for k in ("pass", "warn", "fail", "error")))
    row("**生产首调失败**(JSON+禁词+生成报错)/实际调用", lambda x: pct(x[3]["prod_fail"], x[3]["attempted"]))
    row("  JSON 解析失败", lambda x: str(x[3]["json_fail"]))
    row("  禁词命中", lambda x: str(x[3]["forbidden"]))
    row("  生成侧报错(含上下文超长)", lambda x: str(x[3]["gen_error"]))
    row("连带失败(上游坏导致未调用)", lambda x: str(x[3]["cascade"]))
    for k in RED_LINES:
        row(f"红线:{k}", lambda x, k=k: str(x[5][k]))
    row("延迟 中位/P90/最大(秒)", lambda x: f"{q(x[6], .5)}/{q(x[6], .9)}/{q(x[6], 1)}")
    print()
    for label, rows, meta, s, cats, red, lat in runs:
        print(f"### {label} 全部失败类别\n")
        for k, v in cats.most_common():
            print(f"- {v} × {k}")
        print()


main()
```

### `~/qc-eval/blind_pack.py`

```python
"""盲评包(仓库外临时脚本)。用法:
python ~/qc-eval/blind_pack.py --tag zh --out <包目录> --seal <密封映射.json> \
    --cases case_01,case_05 --modules m0_structure,m1_talent \
    GLM=<run_dir> DeepSeek=<run_dir> Claude=<run_dir> GPT=<run_dir> Gemini=<run_dir>
每个条目独立随机打乱版本字母;映射写进 --seal(只存本机,评审交卷前不得推送)。
可多次调用,同一个 --seal 会累加。"""
import argparse
import json
import secrets
from pathlib import Path

ap = argparse.ArgumentParser()
ap.add_argument("--tag", required=True)
ap.add_argument("--out", required=True)
ap.add_argument("--seal", required=True)
ap.add_argument("--cases", required=True)
ap.add_argument("--modules", required=True)
ap.add_argument("--case-labels", default=None, help="可选 JSON 文件:case_XX → 显示名(真人包用)")
ap.add_argument("runs", nargs="+")
a = ap.parse_args()

runs = [(lbl, Path(p)) for lbl, _, p in (r.partition("=") for r in a.runs)]
out, seal_path = Path(a.out), Path(a.seal)
out.mkdir(parents=True, exist_ok=True)
seal = json.loads(seal_path.read_text(encoding="utf-8")) if seal_path.exists() else {}
labels = json.loads(Path(a.case_labels).read_text(encoding="utf-8")) if a.case_labels else {}
rng = secrets.SystemRandom()

pvs = set()
for _, d in runs:
    meta = json.loads((d / "meta.json").read_text(encoding="utf-8"))
    pvs.add(json.dumps(meta.get("identity", {}).get("prompt_versions"), sort_keys=True))
if len(pvs) != 1:
    raise SystemExit(f"各 run 的 prompt_versions 不一致,不能放进同一个盲评包:{pvs}")


def render(obj, path=""):
    lines = []
    if isinstance(obj, dict):
        for k, v in obj.items():
            lines += render(v, f"{path}.{k}" if path else k)
    elif isinstance(obj, list):
        for i, v in enumerate(obj, 1):
            lines += render(v, f"{path}[{i}]")
    else:
        lines.append(f"**{path}**:{obj}\n")
    return lines


for case in a.cases.split(","):
    for module in a.modules.split(","):
        item = f"{a.tag}__{case}__{module}"
        order = runs[:]
        rng.shuffle(order)
        mapping = {}
        title = labels.get(case, case)
        body = [f"# {a.tag} · {title} · {module}\n"]
        for i, (lbl, d) in enumerate(order):
            letter = chr(ord("A") + i)
            mapping[letter] = lbl
            body.append(f"\n---\n\n## 版本 {letter}\n")
            f = d / case / module / "response.json"
            if f.exists():
                body += render(json.loads(f.read_text(encoding="utf-8")))
            else:
                body.append("(该版本生成失败,无输出)\n")
        (out / f"{item}.md").write_text("\n".join(body), encoding="utf-8")
        seal[item] = mapping
seal_path.write_text(json.dumps(seal, ensure_ascii=False, indent=2), encoding="utf-8")
print(f"写出 {len(a.cases.split(',')) * len(a.modules.split(','))} 个条目 → {out};映射累计 {len(seal)} 条 → {seal_path}")
```
