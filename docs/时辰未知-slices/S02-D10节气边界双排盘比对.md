# S02 D10 节气边界双排盘比对

- **类型**: AFK
- **Blocked by**: S01(在 hour_known=false 路径之上)
- **覆盖决策**: D10(节气边界双排盘)/ 依赖表「节气边界依赖」行(立春→年柱+生肖;节交界→月柱→调候+得令+大运序列)
- **Parent**: `docs/时辰未知设计决策.md`

## What to build

`hour_known=false` 时,年/月柱在节气交界日并非确定。检测与降级:

1. **双排盘比对**:对该出生日(12:00 占位同款时区/真太阳时链路)的 00:00 与 23:59 各排一次,比对**年柱 / 月柱**干支——不一致的柱标 unknown(节气交界与子时无关,00:00/23:59 探针对年月柱成立)。**日柱比对不得直接复用 00:00/23:59 探针**(此为对 Parent D10「比对年/月/日柱」字面措辞的有意偏离,理由如下):setSect(1) 下墙钟 23:59 的真太阳时几乎必落 [23:00,24:00) 换日窗 → **次日**日柱(lunar_python 实证:2024-05-20 的 00:00-22:59=甲申、23:00-23:59=乙酉),而 00:00 为当日——字面实现会让**所有**无时辰用户日柱 unknown,与 Parent D3「答否→日柱完全确定」及 S05「三柱盘」前提直接冲突。日柱歧义的正确判定域是「**排除换日窗后的当日主体区间**」是否横跨两个日柱,等价判据:**墙钟日起点(00:00 经真太阳时调整后)是否早于前一日的 23:00 换日点**(即 offset < 约 −60min 的西偏场景,如喀什 −176min → 墙钟凌晨段落入前一真太阳日)。命中 → 日柱 unknown,走与 late_night=是 同路径(D5 全拦截分支)。日柱与 S01 late_night 是**两层互补的网**:late_night=是/不确定 → S01 已置 unknown;late_night=否 仍可能漏(「否」答者未必把自己凌晨出生归入「半夜 11 点之后」)——西偏凌晨正是该网目标。东八区标准经度下该判据恒不命中(与 D3 一致),不是漏报
2. **响应标记**:歧义标记字段(如 `pillar_ambiguity: {year: bool, month: bool, day: bool}` 或等价显式表达),进响应 + `calc_rule_snapshot` + content_hash(README 红线「日期 + late_night + 歧义标记参与」,S01/S02 共同落实;日柱歧义标记与 late_night=是/不确定 是同一终态的两种来源)
3. **命中后果级联**:
   - 月柱歧义 → 调候(查月支)与得令(`DELING_WEIGHT=5`)不可用 → strength 维持 `unknown_hour` 语义(本就不可用,但月柱歧义时连三柱叙事的月柱部分也要置空)、**大运干支序列置 unknown**(大运从月柱起排)
   - 年柱歧义(立春日)→ 年柱置 unknown + **生肖置 null**(`year_branch_zodiac=null`),供 S08 生肖屏降级
   - 日柱歧义 → 与 S01 `late_night=是/不确定` 同终态:日主系派生输出置空,内容侧走 D5 全拦截分支(深度解析不进内容页 S07 / 每日运势全拦 S09)
4. **确定性**:同输入同输出;比对用 lunar_python 节气表(精确到分),不自算节气

不命中(年/月柱节气界口径 ≈96% 用户;日柱网仅西偏经度凌晨场景命中,东八区标准经度恒不命中)→ 零歧义标记,响应与 S01 基础态一致。

## Acceptance criteria

- [ ] 立春日当天出生 + `hour_known=false` → 年柱 unknown + `year_branch_zodiac=null` + 歧义标记
- [ ] 任一节交界日(12 节/年)出生 + `hour_known=false` → 月柱 unknown + 大运序列置 unknown + 歧义标记
- [ ] 墙钟↔真太阳时换日窗偏移场景(如 Asia/Shanghai 时区 + 经度 <105°E)+ `hour_known=false` + `late_night=false` → 当日主体区间横跨两日柱 → 日柱 unknown(与 late_night=是 同路径,日主派生置空、S09 每日运势全拦)
- [ ] 普通日子出生 + `hour_known=false` → 无歧义标记,年月柱照常(与 S01 输出一致)
- [ ] `hour_known=true` → 永不触发比对(老路径零开销)
- [ ] 歧义标记参与 content_hash:同日有/无歧义 → 不同 hash;歧义状态进 calc_rule_snapshot
- [ ] pytest:立春/节交界/普通日三组用例,含回归佐证(参考现有 `tests/test_bazi_calculate.py` 立春用例附近)
- [ ] 生肖 null 的响应字段 iOS 侧可解码(S05/S08 消费,本 slice 只保证契约)
