# S02 D10 节气边界双排盘比对

- **类型**: AFK
- **Blocked by**: S01(在 hour_known=false 路径之上)
- **覆盖决策**: D10(节气边界双排盘)/ 依赖表「节气边界依赖」行(立春→年柱+生肖;节交界→月柱→调候+得令+大运序列)
- **Parent**: `docs/时辰未知设计决策.md`

## What to build

`hour_known=false` 时,年/月柱在节气交界日并非确定。检测与降级:

1. **双排盘比对**:对**候选墙钟区间的首末时刻**(占位同款时区/真太阳时链路)各排一次,比对**年柱 / 月柱**干支——不一致的柱标 unknown。端点随 late_night 收窄(否 00:00/22:59:59、是 23:00/23:59:59、不确定 00:00/23:59:59),与日柱共用 `day_pillar_candidate_wall_interval`。**探针不得固定探全天**(2026-09-01 code review 修正):立春 ≈10:11 的日子,答「是」的用户整段在立春后、年柱本确定,固定探针会误判歧义并 null 掉生肖——与日柱轴修掉的是同一个错。一日至多一个节气,端点比对充分。**日柱不走这对探针**(此为对 Parent D10 原「比对年/月/日柱」字面措辞的修正,Parent 已于 2026-09-01 同步改口径):setSect(1) 下墙钟 23:59 的真太阳时几乎必落 `[23:00,24:00)` 换日窗 → **次日**日柱(lunar_python 实证:2024-05-20 的 00:00-22:59=甲申、23:00-23:59=乙酉),而 00:00 为当日——字面实现会让**所有**无时辰用户日柱 unknown,与 D3「三柱盘」前提直接冲突。

**日柱统一走 D3 的区间测试**(Parent D3 已写死,本 slice 只负责实现,不再自定判据)。原分割写的「offset < 约 −60min 的西偏场景」是**单边近似,不要照实现**——2026-09-01 review 实测它两个方向都错:

| 场景 | offset | late_night | 精确结论 | 单边规则 |
|---|---:|---|---|---|
| 喀什 75.98°E | −176 | 是 | **确定**(真太阳时 20:04-21:04 同日) | 误判歧义 → 过度降级 |
| 成都 104.1°E | −63 | 是 | **确定** | 误判歧义 → 过度降级 |
| 喀什 75.98°E | −176 | 否 | 歧义 | 一致 |
| 上海 121.5°E | +6 | 否 | **歧义**(墙钟 22:54-23:00 落次日) | 误判确定 → 静默给错日柱 |
| 抚远 134.3°E | +57 | 否 | **歧义**(墙钟 22:00-23:00 落次日) | 误判确定 → 静默给错 |

正确实现(D3 三步,一个函数,无 −60 魔数):

```
候选墙钟区间 = 否 → [00:00,23:00) / 是 → [23:00,24:00) / 不确定 → [00:00,24:00)
真太阳时区间 = 候选区间 + offset_minutes
日柱歧义     ⟺ 该区间内包含一个真太阳时 23:00 换日点
```

「不确定」恒歧义由该测试自然得出(任何 24h 区间必含且仅含一个 23:00 点),不需另写分支。东八区标准经度 + 答「否」不命中(与 D3 一致);西偏答「是」不命中(**这是原规则误伤的人群,修正后他们保有完整日柱与免费内容**)。


2. **响应标记**:歧义标记字段(如 `pillar_ambiguity: {year: bool, month: bool, day: bool}` 或等价显式表达),进响应 + `calc_rule_snapshot` + content_hash(README 红线「日期 + late_night + 歧义标记参与」,S01/S02 共同落实;日柱歧义标记与 late_night=是/不确定 是同一终态的两种来源)
3. **命中后果级联**:
   - 月柱歧义 → 调候(查月支)与得令(`DELING_WEIGHT=5`)不可用 → strength 维持 `unknown_hour` 语义(本就不可用,但月柱歧义时连三柱叙事的月柱部分也要置空)、**大运干支序列置 unknown**(大运从月柱起排)
   - 年柱歧义(立春日)→ 年柱置 unknown + **生肖置 null**(`year_branch_zodiac=null`),供 S08 生肖屏降级
   - 日柱歧义 → 与 S01 `late_night=是/不确定` 同终态:日主系派生输出置空,内容侧走 D5 全拦截分支(深度解析不进内容页 S07 / 每日运势全拦 S09)
4. **确定性**:同输入同输出;比对用 lunar_python 节气表(精确到分),不自算节气

不命中(年/月柱节气界口径 ≈96% 用户;日柱按 D3 区间测试,东八区标准经度 + 答「否」不命中)→ 零歧义标记,响应与 S01 基础态一致。

## Acceptance criteria

- [ ] 立春日当天出生 + `hour_known=false` → 年柱 unknown + `year_branch_zodiac=null` + 歧义标记
- [ ] 任一节交界日(12 节/年)出生 + `hour_known=false` → 月柱 unknown + 大运序列置 unknown + 歧义标记
- [ ] 西偏场景(如 Asia/Shanghai + 75.98°E 喀什)+ `late_night=false` → 日柱 unknown
- [ ] **西偏 + `late_night=true` → 日柱确定**(offset −176 → 真太阳时 20:04-21:04 同日;防「答是即 unknown」的过度降级回归)
- [ ] **东偏场景(如 134.3°E 抚远,offset +57)+ `late_night=false` → 日柱 unknown**(防单边规则漏报回归)
- [ ] `late_night=null` → 恒 unknown(区间测试自然结论)
- [ ] **立春日 + `late_night=true` → 年/月柱确定、`year_branch_zodiac` 非 null、大运序列不清空**(探针收窄回归,原固定探针会误判)
- [ ] **立春日 + `late_night=false` → 年/月柱仍歧义**(反向护栏:收窄不等于不检测)
- [ ] 节交界日 + `late_night=true`(节气在当日 23:00 前)→ 月柱确定
- [ ] 普通日子出生 + `hour_known=false` → 无歧义标记,年月柱照常(与 S01 输出一致)
- [ ] `hour_known=true` → 永不触发比对(老路径零开销)
- [ ] 歧义标记参与 content_hash:同日有/无歧义 → 不同 hash;歧义状态进 calc_rule_snapshot
- [ ] pytest:立春/节交界/普通日三组用例,含回归佐证(参考现有 `tests/test_bazi_calculate.py` 立春用例附近)
- [ ] 生肖 null 的响应字段 iOS 侧可解码(S05/S08 消费,本 slice 只保证契约)
