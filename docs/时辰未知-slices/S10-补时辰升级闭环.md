# S10 补时辰升级闭环

- **类型**: AFK
- **Blocked by**: S07(付费墙拦截态 CTA)、S09(每日运势末尾触点位)
- **覆盖决策**: D7 全部(三触点 + 补时辰入口本身 + 永久无时辰静默态 + hash 重建老盘归档)/ D9 二期
- **Parent**: `docs/时辰未知设计决策.md`

## What to build

1. **补时辰 sheet**(单一入口组件):只补时辰一个字段(wheel 或时辰快捷选),不重填姓名/性别/地点;可选「改答半夜问题」不需要——补的是确定时辰,`late_night` 作废清空;提交 → 以「原出生日期 + 新时辰 + 原 gender/place」重算 → **新 content_hash 新命盘**,老三柱盘归档保留(对齐生肖决策 Q20:编辑场景隔离,本入口只管补时辰)
2. **三触点接线**(全部指向同一 sheet):
   - 命盘时柱列留白 dashed(S05 占位)→ 点击进 sheet;**入口也作用于合盘 roster 里的他人命盘**(他人盘补时辰同样 hash 重建,对级关系自然重算)
   - 每日运势末尾一行静默文字(S09 预留位):「这份运势只用了你的日柱。补上时辰可以看到时辰运势与喜忌。」点击进 sheet——**静默行,不是弹窗**
   - 付费墙 CTA(S07 占位)→ 进 sheet;同时落地 D9 二期「付费墙拦截页文案适配」:S07 一期临时一句话 → 正式版文案(为什么拦 + 补时辰引导),静默态下按第 4 条降为中性
3. **Profile 常驻位**:命主卡「补充出生时刻」入口(静默态下唯一保留的主动入口)
4. **「我确实不知道」静默态**:sheet 内/触点旁提供「我确实不知道」确认态;开启后:三触点不再主动提示(留白列保留、运势末尾行与付费墙 CTA 文案降为中性),Profile 入口保留;存档进 payload(decodeIfPresent)
5. **补后体验闭环**:新盘 hash → 缓存自然重建 / 每日运势新生成 / 付费墙恢复(判据 payload hour_known=true);**entitlement 重绑不做**(mismatch_reject 独立课题——但因 S07 拦购买,无时辰用户不存在待迁移权益,闭环无死角)

## Acceptance criteria

- [ ] 四触点(时柱列/运势末尾/付费墙 CTA/Profile)全部进同一 sheet;sheet 只含时辰输入
- [ ] 补时辰提交 → 新命盘(content_hash 与老盘不同)、老盘归档可查;他人盘补时辰同
- [ ] 补后:hour_known=true 判据生效,付费墙恢复价格与购买,每日运势为完整版
- [ ] 「我确实不知道」开启后三触点静默,Profile 入口仍在;关闭静默态可恢复提示
- [ ] late_night 在补时辰后清空;payload 新字段 decodeIfPresent
- [ ] XCTest:触点路由 / hash 重建 / 静默态开关 / 补后判据翻转
