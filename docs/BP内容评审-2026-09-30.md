## 3. 修改方案

按"改动面 / 是否碰守护栏"切成 7 个 slice。**S1-S4 纯 iOS 文案/布局，不碰 prompt、不碰计算，可先做**；S5-S7 碰 backend prompt 或契约，受 CLAUDE.md 守护栏约束。

### S1 喜忌去绝对化（R11，P0，纯文案 + 一行释义）

- EN：`deepanalysis.hero.sideNote.unfavorable` "Avoid %@" → **"Less supportive %@"**；`deepanalysis.xiji.unfavorable` "Avoid" → **"Less supportive"**；`deepanalysis.xiji.favorable` "Favorable" → **"Favored"**；hero 竖注 "Favorable %@" → **"Favored %@"**（与 CONTEXT.md 词条对齐，i18n 词表 `忌神` 显示层改 "Less supportive element"，术语层保留 Unfavorable Element 作 prompt 用语）
- zh / zh-Hant：hero 竖注"喜火土金 · 忌木水"**保留**（中文命理用户对"喜/忌"认知稳定，也是专业辨识度来源）；XijiCard 标签"忌讳" → **"忌神"**（"忌讳"带生活禁忌语感，"忌神"是术语本名，与 a11y 文案已一致）
- 三语：XijiCard 底部加一行常驻释义（caption，inkMuted）——
  - zh："喜忌指五行对命局平衡的助益方向，不是生活禁忌（不涉及颜色、方位、职业的取舍）。"
  - en："Favored and less supportive describe how each element balances this chart — not things to avoid in daily life."
- 忌神 chip 描边色 `cinnabar` → 保持（DESIGN.md 允许小元素朱红）；**不**加更多警示色
- 验证：xcstrings 三语补齐；无 prompt 改动，不触发 check_prompt_sync / evalkit

### S2 Me 页：命盘先于账号（R4 + R5，P1，纯 iOS）

- `PrimaryProfileInfo.metaLine` 追加日主段："1984 年生 · 甲子 · 日主甲木" / EN "Born 1984 · 甲子 · Day Master 甲 Wood"（从 `response.pillars.day?.gan` + 五行取，时辰未知不影响日柱，照常显示；日柱歧义时省略该段，不猜）
- "观盘 ›" → "查看完整命盘 ›" / "View full chart ›"，字号 11.5 → 13
- `loginBox` 从命主块之后**移到名册之后**（顺序：命主块 → 补时辰 → 名册 → 登录盒 → 已购 → 设置 → 关于）；视觉收成"一行说明 + 按钮"，印章 44 → 26pt，去虚线框改 hairline 上分隔（DESIGN.md：dashed 专用于锁框/临时态，登录不是临时态）
- 零盘态（名册空）时登录盒仍须可见（沿用 `ProfileView.swift:93` 注释约束）
- 验证：ProfileView 快照/UITest 的顺序断言需要同步

- `explanations` 表全部改写为"第二人称 / 两人视角 + 一句结果"，示例：

### S4 深度解析：命书框架说清 + 章名人话化（R8 + R12 + R13，P1，纯文案）

### S6 Today 结构化今日洞察（R1，P0，backend + prompt + iOS，⚠ 守护栏）

**目标结构**（对齐评审示例，控制总篇幅）：

```
今日一句（标题句，≤16 字 / ≤8 words）      ← AI
事业 · 一句                                ← AI
关系 · 一句                                ← AI
精力 · 一句                                ← AI
今日信号：火 ↑ · 木 ↓                        ← 引擎（确定性）
```
