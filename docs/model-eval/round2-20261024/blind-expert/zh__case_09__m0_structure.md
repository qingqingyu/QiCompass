**main_axis.dominant**:食神

**main_axis.secondary**:偏财

**main_axis.latent**:劫财、正财、伤官、正官、偏印、比肩、七杀

## 版本 C

**main_axis.headline**:你靠做出来的东西说话，机会跟着手艺来。

**main_axis.body**:主导是食神，也就是自然流露的产出、手艺和享受——你会的东西自己长出来，不靠人逼。次要一股是财星：偏财是抓机会、调动资源的嗅觉，正财是一点点攒下来的积累，两条路都开着。还有一股同辈的力量在分资源：劫财，也就是同辈之间的竞争、和人抢资源；真正藏着没怎么用的是偏印——一个人钻研偏门学问的那股劲，以及正官、七杀这类来自外部的规则和硬要求。

**main_axis.dominant**:食神

**main_axis.secondary**:偏财、正财、劫财（正财与劫财并列）

**main_axis.latent**:偏印、正官、伤官、比肩、七杀

**main_axis.evidence**:食神权重 8（月干丙火透出，时支巳中丙火再计），为全局最重；偏财权重 7（月支、日支戌中戊土各计，时支巳中戊土再计）；劫财权重 5（年干乙木透出）、正财权重 5（时干己土透出），两者并列第二；偏印权重 3（年支亥中壬水藏而不透）、正官权重 2（月支、日支戌中辛金藏干）、伤官权重 2（月支、日支戌中丁火藏干）、比肩权重 1（年支亥中甲木藏干）、七杀权重 1（时支巳中庚金藏干）、正印权重 0

**core_loop.headline**:做出东西 → 换来钱和机会 → 耗空自己 → 再做新的。

**core_loop.from**:食神

**core_loop.to**:偏财

**core_loop.flow**:你先把手上的东西做出来——一份能用的方案、一道拿手的菜、一个跑得起来的东西——别人看见了就愿意给钱给机会。但你自己这本账是亏的：每做一轮，消耗的是你自己的精力，补回来的进账又快快地花出去、分出去。所以这个圈子转得快，你人却越转越薄。

**core_loop.driver**:日主甲木偏弱，喜水木帮身；食神权重 8 为最重，偏财 7 次之，身弱而食伤生财，产出与进财都在泄耗日主，年干乙木劫财（权重 5）再分走一部分资源，帮身的水只有年支亥中壬水（偏印权重 3），藏而不透，补给跟不上消耗

**core_loop.leak**:代价是进得多、留得少：你把事情做成了，钱和成果却过手就散——分给同行、花在享受、垫进下一个想做的事，很难攒下属于自己的那份。

眼下给每一笔进账和每一次付出先划出「不动的一份」，先补给、再扩张，别让下一件事把刚攒的又垫进去。

**core_loop.evidence**:食神权重 8、偏财权重 7、正财权重 5、劫财权重 5，日主甲木偏弱、喜木水（用神候选为木、水）；水在四柱透出计数仅 1（年支亥），偏印壬水藏于亥中未透，帮身之力薄；大运 41 岁段：庚寅运，寅为木支，日主得根帮身；当前 31 岁段：己丑运，干支皆土，财星之地，泄耗更重

**structure_type.one_line**:你先做出能看能用的东西，钱和机会随后找上来；只是进来的快、出去的也快，自己那根支柱偏细，转得越快越要留意别把自己转空。

**capability_source.headline**:最强在要你从零拿出实物、当场见真章的时候；最弱在要熬年头、按资历一步步攒的时候。

**capability_source.evidence**:食神权重 8 为主导，偏财 7、正财 5 紧随，食伤与财星构成「产出—变现」的主干；正印权重 0，全盘无正印，体系、资质、靠山一类的积累没有落点；正官 2、七杀 1 皆藏于地支（戌中辛金、巳中庚金），未透，外部规则与名分对你的约束力弱，这也意味着按资历、按章程上位的路径不是你的主路

**structure_fingerprint**:靠动手产出换钱和机会，进得快散得也快，自身根气偏弱，先补自己再扩张。

**main_axis.secondary**:劫财、正财

**main_axis.latent**:偏印

**core_loop.headline**:做出东西 → 找机会换成钱 → 再投入下一轮产出。

**core_loop.from**:食神

**core_loop.to**:偏财

**core_loop.flow**:你先把想法落成一个能跑、能用的东西，这是食神在起作用；东西一成形，你马上开始找谁能用、谁愿意付钱，偏财的嗅觉让你在别人还在确认需求时就已经把资源调动起来。换来的钱和机会又变成下一轮的原料，让你继续做下一个东西。劫财在旁边盯着，每次分资源时你都会下意识争一争，这让你不容易被压价，但也让合作多一层摩擦。
