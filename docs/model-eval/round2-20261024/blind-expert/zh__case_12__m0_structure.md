## 版本 A

**main_axis.headline**:你靠识别机会、调动资源并回应要求向前推进。

**main_axis.body**:主导是偏财，也就是抓机会、调动资源的嗅觉；你会先看资源怎么组合，再决定怎么推进。其次是伤官（表达欲和挑战规矩的锋芒）、七杀（外部压力和硬要求）与食神（自然流露的产出和手艺）；你会用表达和交付回应硬要求。较隐的是正印（体系、资质和靠山）、正财（稳定收入和逐步积累）、正官（规则、职位和名分）、劫财（同辈竞争和争资源）与偏印（偏门学识和独自钻研）；它们在主线中不如前几者显眼。

**main_axis.dominant**:偏财

**main_axis.secondary**:伤官、七杀、食神

**main_axis.latent**:正印、正财、正官、劫财、偏印

**main_axis.evidence**:偏财权重 8，为最高；己透在年干，丑中也藏己。伤官权重 6，来自两处巳中所藏的丙；七杀权重 6，辛透在时干，丑中也藏辛；两者并列次高。食神权重 5，丁透在月干。正印权重 3，亥中藏壬；正财权重 2、正官权重 2，均见于两处巳的藏干；劫财权重 1，亥中藏甲；偏印权重 1，丑中藏癸。乙木日主偏弱。四柱透出字的五行计数为木 1、火 3、土 2、金 1、水 1。

**core_loop.headline**:找到机会 → 做成成果 → 接住更硬要求 → 再协调资源

**core_loop.from**:偏财

**core_loop.to**:七杀

**core_loop.driver**:乙木日主偏弱，偏财权重 8，伤官与七杀各 6，食神 5；资源调度、表达产出和外部要求都较显眼。正印权重 3、偏印 1，劫财 1，日主的生扶力量相对轻；候选五行中有木、水。

**core_loop.leak**:机会判断快、接活快，但同时追着资源和硬要求跑，容易把完成交付放在整理方法、沉淀成果之前。事情一多，精力就会分给协调和补位。
约32岁起的那十年（癸酉运），运里出现水；你可以观察先补信息、借助支持再接任务的做法，是否更容易持续。
现在可以在接任务前列清资源、时间和决策权限，并在交付后留出复盘时间，把临时应对整理成下次可用的做法。

**core_loop.evidence**:乙木日主偏弱；偏财权重 8，伤官与七杀各 6，食神 5，正印 3、偏印 1、劫财 1。候选五行包含木、水。大运列表中 32 岁段为癸酉运，癸属水。

**structure_type.name**:机会调度交付型

**structure_type.one_line**:你先判断哪里有资源可调，再把想法变成可交付的内容；外部要求会推动你继续协调资源、提高完成标准。

**capability_source.headline**:最强在客户临时改需求、需要你重组资源并交方案的时候；最弱在职责模糊、资源有限却要求你长期独自扛指标的时候。

**capability_source.text**:你能把发现机会、调动资源和做出成果接在一起。例如客户临时提出新需求、团队手头资源还没理清时，你会先确认限制条件，再拼出可执行的方案并协调人手。
