**main_axis.dominant**:正印、偏印、劫财（并列最重）

**main_axis.secondary**:伤官、正财

**main_axis.latent**:官杀

**core_loop.to**:印星

**core_loop.leak**:代价是你把事做成了，但不太会把它变成钱或可见的成果：伤官和正财虽然在场，但印星和劫财更重，精力先花在学东西和守位置上，轮到包装、定价、谈判时就没那么主动了。

**structure_type.name**:扛压型积累者
