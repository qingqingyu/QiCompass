【禁止】
- 不讲吉凶、神煞、刑冲破害的凶险叙事

- 字符串值内引用词语一律用中文引号「」，禁止半角双引号 " ——它会让整个 JSON 无法解析
- 输出只含最终定稿的纯 JSON：不含草稿、自检说明、修改前后对比或任何 JSON 之外的文字
