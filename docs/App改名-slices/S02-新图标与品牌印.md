# S02 新图标与品牌印「观」

- **类型**: AFK(出稿)+ HITL(用户选稿)
- **Blocked by**: S01
- **Parent**: `docs/App改名KnowFate设计决策.md` 决策 2

## What to build

1. **对照现状**:现有图标 `ios/QiCompass/QiCompass/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png` = 旧宣纸底 + 居中朱红宋体「玄」,无边框、无印框
2. **出 3 版 × 2 字形(简体「观」/ 繁体「觀」)共 6 张图标**(1024×1024,不透明 PNG,无 alpha,无圆角 —— iOS 自动加):
   - A:与现有完全同构 —— 宣纸底 + 居中朱红宋体「观 / 觀」,字号与视觉重心对齐旧图
   - B:朱印方框 —— 朱红方印 + 宣纸色阴文「观 / 觀」(与 App 内 SealStamp 同语言)
   - C:墨圆 + 朱红「观 / 觀」—— 焦墨 Enso 环绕(品牌指纹),字略小
   - 字体用打包的思源宋体子集:「观」用 `QiSongti-Regular.otf`,「觀」用 `QiSongtiTC-Regular.otf`;颜色用 DESIGN.md token(宣纸 `#E7E2D5` 或现有图标底色 / 朱红 `#A83226`)
3. **出一张对比板**(HTML 或 PNG):三版 × 两字形 × 三个尺寸(1024 / 180 / 60)+ 放在模拟主屏幕(亮 / 暗壁纸)上的效果,与旧「玄」图标并排。放 `docs/design-ref/app-icon-guan/`
4. **用户选定后**:替换 `AppIcon-1024.png`;生成脚本(若写了)和选稿记录一起进 git

## 进度(2026-11-25)

- ✅ 出稿完成:`docs/design-ref/app-icon-guan/`——`icon.html`(渲染模板)+ `render.js`(Playwright 生成)+ `png/{A,B,C}-{sc,tc}.png`(6 张 1024×1024 不透明 PNG)+ `board.html`(对比板:新旧并排、180 / 60 / 40 三尺寸、亮暗主屏模拟)
- 配色沿用现有图标实测取色:米色底 `#F5EFE1`、朱红 `#C33B3B`(与 DESIGN.md 的 cinnabar `#A83226` 不同,现有图标即如此,沿用以保持连续)
- 待用户:选版本与字形;选定后替换 `AppIcon-1024.png` 并写选稿记录

## 依赖约束

- 生成图片优先用 HTML + 环境里预装的 Playwright 截图(无新依赖);若需要 Pillow 等库,先征得同意
- 不引入任何图标生成服务

## Acceptance criteria

- [ ] 对比板含 3 版 × 3 尺寸 × 亮暗壁纸,并排旧图标
- [ ] 60px 尺寸下字清晰可辨(用户目验;「觀」笔画多,重点看它在小尺寸是否糊成一团)
- [ ] 用户定下图标用「观」还是「觀」(图标全球只有一个,不随语言切换)
- [ ] 用户选稿记录写进 `docs/design-ref/app-icon-guan/README.md`(日期、选中版本、理由)
- [ ] 新 `AppIcon-1024.png` 为 1024×1024、无 alpha 通道(用 `sips -g hasAlpha` 或等效命令验证)
- [ ] App 内品牌印与图标字形一致:简体界面「观」、繁体界面「觀」(与 `BaziFont` 的简繁字体分流一致)
