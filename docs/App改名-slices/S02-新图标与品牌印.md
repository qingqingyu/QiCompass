# S02 新图标与品牌印「知」

- **类型**: AFK(出稿)+ HITL(用户选稿)
- **Blocked by**: S01
- **Parent**: `docs/App改名KnowFate设计决策.md` 决策 2

## What to build

1. **对照现状**:现有图标 `ios/QiCompass/QiCompass/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png` = 旧宣纸底 + 居中朱红宋体「玄」,无边框、无印框
2. **出 3 版「知」图标**(1024×1024,不透明 PNG,无 alpha,无圆角 —— iOS 自动加):
   - A:与现有完全同构 —— 宣纸底 + 居中朱红宋体「知」,字号与视觉重心对齐旧图
   - B:朱印方框 —— 朱红方印 + 宣纸色阴文「知」(与 App 内 SealStamp 同语言)
   - C:墨圆 + 朱红「知」—— 焦墨 Enso 环绕(品牌指纹),字略小
   - 字体用打包的思源宋体子集 `QiSongti-Regular.otf`;颜色用 DESIGN.md token(宣纸 `#E7E2D5` 或现有图标底色 / 朱红 `#A83226`)
3. **出一张对比板**(HTML 或 PNG):三版 × 三个尺寸(1024 / 180 / 60)+ 放在模拟主屏幕(亮 / 暗壁纸)上的效果,与旧「玄」图标并排。放 `docs/design-ref/app-icon-zhi/`
4. **用户选定后**:替换 `AppIcon-1024.png`;生成脚本(若写了)和选稿记录一起进 git

## 依赖约束

- 生成图片优先用 HTML + 环境里预装的 Playwright 截图(无新依赖);若需要 Pillow 等库,先征得同意
- 不引入任何图标生成服务

## Acceptance criteria

- [ ] 对比板含 3 版 × 3 尺寸 × 亮暗壁纸,并排旧图标
- [ ] 60px 尺寸下「知」字清晰可辨(用户目验)
- [ ] 用户选稿记录写进 `docs/design-ref/app-icon-zhi/README.md`(日期、选中版本、理由)
- [ ] 新 `AppIcon-1024.png` 为 1024×1024、无 alpha 通道(用 `sips -g hasAlpha` 或等效命令验证)
- [ ] App 内品牌印 `SealStamp(character: "知")` 与图标字形一致(同一字体)
