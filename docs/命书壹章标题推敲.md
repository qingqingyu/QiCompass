## 已定原则

1. **标题=呈现**:章名/副题必须与章内实际呈现同一套语言(路 C:只动命名层,prompt 不碰)
2. **四节构造定案**:两节机器(主线/循环,喂全书)+ 一节礼物(类型名)+ 一节预告(能力,贰章广告),一节不多一节不少
3. **小节名=读者带着进章的问题**:素材四问句原样,不提炼;「十神」保留(专业签名,正文自带白话释义)
4. **章名=索引不是钩子**(2-5 字名词);钩子的活归副题
5. 改动半径:章名/副题 = ModuleDefinitions + xcstrings 三语 + 付费墙硬编码;小节名 = iOS ChapterContent.labels(不动 backend)
