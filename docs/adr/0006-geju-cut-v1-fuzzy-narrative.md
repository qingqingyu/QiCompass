# 0006 — 格局判定 v1 砍掉,LLM 模糊叙事

Status: accepted (2026-07-09)

传统命理的格局硬分类(正官格 / 偏印格 / 食神格 / ...)在 v1 **完全不实现**。LLM prompt 用"命局呈现××倾向"模糊叙事,严禁给出"正官格 / 偏印格"等硬分类结论。

**Why**: 格局判定是命理最大的流派争议来源。同一命盘,不同门派给出的格局不同。强行规则化会陷入"哪派是对的"无解争论;交给 LLM 判断又会破坏确定性(违反 ADR 0004)。MVP 阶段砍掉格局判定是降低复杂度 + 避免争议的双重保险。

**Surprising without context**: 用户期待看到"我是什么格",但产品故意不给。LLM prompt 里硬性约束 "不得给出硬性格局分类",看起来像"功能阉割",其实是诚实降级。

**Real trade-off**:
- ✅ v1 砍掉 — 避免流派争议 + 降低实现复杂度 + 保护确定性
- ❌ 规则引擎判格局 — 陷入流派分歧,与"专业不忽悠"反方向
- ❌ LLM 判格局 — 破坏确定性,同盘不同次给出不同格局

**Consequences**: 严肃命理爱好者可能觉得"不专业",接受这个代价。延后到 v2,基于付费用户反馈立项,届时再决定走规则引擎还是只做定性标签。从格 / 专旺作为"特征检测"(不是格局判定)单独处理 — 见 ADR 0007。
