# 0005 — 神煞 = 20 个固定清单,《三命通会》单一来源

Status: accepted (2026-07-09)

八字神煞(天乙贵人 / 文昌 / 华盖 / 羊刃 / 桃花 等)固定 20 个清单 — 11 吉神 + 9 凶煞,所有起法统一以《三命通会》为准,自写静态查表(`SHENSHA_TABLE`)。

**Why**:
1. `lunar_python` **不给**这 20 个八字神煞,必须自己实现
2. 神煞系统最大的坑是各家起法冲突(《三命通会》《渊海子平》《滴天髓》说法不一),决不东拼西凑 — 一个来源查到底,可复现

**Why 20 个**: 太少(<10)命书内容单薄 LLM 没素材;太多(>30)LLM 内容发散命中率虚高。20 个足够撑起命书丰富度,又控制住 LLM 发散。

**Surprising without context**: 凶煞清单里"红艳"传统中吉凶参半,这里归凶煞以平衡(11 吉 + 9 凶 = 20,不是 10+10)。

**Real trade-off**:
- ✅ 固定清单 + 单一来源 — 确定性 + 可复现 + 控制发散
- ❌ 动态生成(LLM 现场挑)— 不确定 + 易出幻觉 + 流派分歧
- ❌ 扩展到 30+ — LLM 内容失控

**Consequences**: 实现 = 静态查表(日干查表 / 三合局查表),约 2.5-3 工作日完成。对盘用 `lunar_python` 测试套件 + 问真八字 App 抽样 5-10 个真实命盘。
