# 0011 — 合盘定性不给数字分,4 维评估 + 流年同步标签

Status: accepted (2026-07-09)

合盘结果**不给数字分、不引入百分比**。只给 4 维定性评估:

- **五行互补** — 一方多余是否另一方所需
- **日主关系** — 相生 / 相克 / 相比
- **生肖匹配** — 三合 / 六合 / 六冲 / 相刑
- **地支合冲** — 命局整体协调度

外加 3 年流年同步性(同步走强 / 同步承压 / 运势分化 / 难以定性)。

**Why**:
1. 命理合盘给"82 分"这类数字会暗示虚假精确,违反 Memorable Thing "专业不忽悠"
2. 数字分一旦给出,用户会比较"A 比 B 高 3 分"做出关系决策,过度承诺
3. 定性描述("五行互补佳")+ 流年同步标签("同步走强")足够支持用户判断

**Surprising without context**: 国内命理 App(测测 / 知命)默认给数字分,QiCompass 故意不给。LLM prompt 里有硬性约束"绝对禁忌:不得给出必成 / 必分 / 必破财等绝对结论"(后端禁词守卫拦截"百分百 / 一定")。

**Real trade-off**:
- ✅ 定性 + 标签 — 诚实 + 不误导
- ❌ 数字分 — 虚假精确 + 误导关系决策
- ❌ 星级(1-5 星)— 仍然是数字的变种,同样问题

**Consequences**: UI 不能出现 ProgressBar / 百分比 / 星级等量化控件,只能用文字 + 标签 chip。LLM 必须用"佳 / 一般 / 需注意"等定性词。
