# 0002 — 强制 `setSect(1)`,子时换日为产品默认

Status: accepted (2026-07-09)

`lunar_python` 的 `EightChar.setSect(1)` 强制设定为子时换日规则(23:00 后归次日),不允许使用库默认的 `sect=2`(早晚子时)。

**Why**: 库默认 `sect=2`(早晚子时 — 早子时 23:00-00:00 归当日,晚子时 00:00-01:00 归次日)与产品决策"默认 23:00 换日"冲突。如果不强制覆盖,所有跨子时出生的命盘日柱会错位。

**Surprising without context**: 后端排盘封装层第一行必须有 `ec.setSect(1)`,看起来像"魔法配置",其实是与库默认值的强制对齐。漏掉这一行不会立刻报错,只在跨子时命盘上静默出错。

**Real trade-off**: 早子时派(子时全部归次日,`sect=1`)vs 早晚子时派(分两段,`sect=2`)是命理学界的真分歧。产品选 `sect=1` 因为对现代用户更直观("23:00 之后就是明天")。用户可在 UI 切换 `zero_oclock` 触发 `sect=2`,但默认必须是前者。
