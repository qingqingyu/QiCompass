# 0007 — 从格检测 = 简单阈值 + 诚实降级(决策 1b / D3)

Status: accepted (2026-07-10)

约 10% 的命盘是从格 / 专旺(曲直 / 炎上 / 稼穑 / 从革 / 润下)或化气格,这些盘不能硬塞扶抑法(会得反结果)。用 3-4 条简单 if 检测从格特征:

- **专旺格**:本命四柱 8 字中日主同气五行 ≥ 6 个
- **从格**:日主孤立(天干无印 / 比劫同气)+ 某一行 ≥ 5 个

命中输出 `day_master_strength="special_pattern"`,`favorable_elements` / `unfavorable_elements` **留空**,LLM prompt 追加约束:"此命局呈现专旺/从格特征,传统格局判定各派不同,以下解读仅供参考,不下硬性喜忌结论"。

**Why**: 这 10% 用户拿到"喜忌留空 + 诚实告知"比拿到"错的喜忌"强(后者直接破坏信任)。检测规则简单 = 不陷入流派争议(不是完整格局判定,只是阈值标记);LLM 只做"告知"不做"判定",与 ADR 0004(喜忌确定性)+ ADR 0006(格局砍掉)哲学一致。

**Surprising without context**: 看起来"功能不完整"(用户拿不到喜忌),其实是诚实降级 — 与 Memorable Thing "专业不忽悠,不像算命软件" 完全对齐。

**Real trade-off**:
- ✅ 简单阈值检测 + 诚实降级 — 不陷入流派争议,用户拿到真信号
- ❌ 完整格局判定引擎 — 流派分歧巨大,v1 不做(见 ADR 0006)
- ❌ 反转扶抑(从格喜忌反转)— 又掉进格局判定的坑

**Consequences**: 阈值初值(≥6/8、≥5/8)需用真实命盘 spike 验证。命中后 LLM 必须诚实告知,不能编造喜忌。
